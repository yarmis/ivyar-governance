## Document Versioning

All documents are versioned and maintained according to the IVYAR Governance & Oversight Framework.

- **Major versions** (1.0, 2.0) — Significant policy or structural changes
- **Minor versions** (1.1, 1.2) — Clarifications and minor updates
- **Patch versions** (1.1.1) — Typo fixes and formatting

## Contributing

1. All changes must be submitted via Pull Request
2. Changes to legal documents require Legal team approval
3. Changes to governance documents require Compliance team approval
4. Technical documentation requires Technical Lead approval
