# Aircraft Structures Catalog

## Categories

| Category | Examples |
|----------|----------|
| Fuselage | Panels, frames, stringers |
| Wings | Spars, ribs, skins |
| Empennage | Stabilizers, rudder |
| Landing Gear | Struts, wheels, brakes |
| Doors | Passenger, cargo, emergency |

## Data Structure

| Field | Description |
|-------|-------------|
| Part Number | Unique ID |
| Description | Part name |
| ATA Chapter | System code |
| Criticality | Safety level |
| Lead Time | Delivery days |

## Criticality Levels

| Level | Description |
|-------|-------------|
| AOG | Aircraft on ground |
| Critical | Safety of flight |
| Essential | Dispatch required |
| Standard | Normal stock |
