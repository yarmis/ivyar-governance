# Aerospace Governance Model

## Framework

| Layer | Scope |
|-------|-------|
| Executive | Strategy, budget |
| Program | Delivery, schedule |
| Operations | Daily execution |
| Quality | Compliance |

## Decision Authority

| Decision | Level |
|----------|-------|
| Rate change | Executive |
| Supplier change | Program |
| AOG response | Operations |
| Quality hold | Quality |

## Reporting Cadence

| Report | Frequency |
|--------|-----------|
| Executive brief | Weekly |
| Program review | Weekly |
| Ops status | Daily |
| Risk review | Weekly |

## Escalation Path

- Operations to Program: 24h
- Program to Executive: 48h
- Quality: Immediate if safety
