# Line Readiness Index

## Definition

Measures production line capability to deliver aircraft.

## Inputs

| Factor | Weight |
|--------|--------|
| Parts availability | 30% |
| Staffing level | 25% |
| Tooling ready | 20% |
| Station status | 15% |
| Quality holds | 10% |

## Index Scale

| Score | Status | RAG |
|-------|--------|-----|
| 90-100 | Full capacity | GREEN |
| 70-89 | Normal ops | GREEN |
| 50-69 | Constrained | AMBER |
| 0-49 | Critical | RED |

## Usage

- Production planning
- Slot allocation
- Risk briefings
- Leadership reports
