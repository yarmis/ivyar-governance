# IVYAR Domain Structure

## Primary Domains

| Domain | Purpose |
|--------|---------|
| ivyar.org | Main website |
| portal.ivyar.org | Governance portal |
| api.ivyar.org | API services |
| docs.ivyar.org | Documentation |

## Environment Domains

| Domain | Purpose |
|--------|---------|
| staging.ivyar.org | Testing |
| dev.ivyar.org | Development |

## Partner Domains

| Domain | Purpose |
|--------|---------|
| gov.ivyar.org | Ministry access |
| nato.ivyar.org | NATO partners |
| oem.ivyar.org | OEM partners |

## Security

- SSL on all domains
- DDoS protection
- WAF enabled
- Access logging
