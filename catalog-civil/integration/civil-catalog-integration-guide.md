# Civil Catalog Integration Guide

## 1. Overview
Step-by-step instructions for OEMs and partners to integrate catalog data with IVYAR.

## 2. Integration Methods
| Method | Best For | Setup Time |
|--------|----------|------------|
| SFTP Upload | Large batch files | 1-2 days |
| API Push | Real-time updates | 3-5 days |
| Portal Upload | Small datasets | Immediate |

## 3. Data Requirements
- OEM Parts (CSV/JSON) - Required
- Aftermarket Mappings (CSV) - If applicable
- NSN Mappings (CSV) - If available

## 4. Integration Steps
1. Register as Partner (partners@ivyar.org)
2. Prepare Data (validate against schema)
3. Submit Data (SFTP/API/Portal)
4. Review Results

## 5. Contact
- Technical: integration@ivyar.org
- Partnership: partners@ivyar.org
