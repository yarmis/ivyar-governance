# IVYAR Repair Coverage Package
## Government-Facing Overview

This package provides a unified, structured view of IVYAR military repair capability model.
Designed for ministry-level decision makers, logistics planners, and international partners.

### What This Package Contains

- **Executive Summary** - High-level overview of repair capability and key gaps
- **Master Document** - Full R1-R4 repair levels, heatmap, pipeline, metrics
- **Repair Pipeline Diagram** - Visual repair flow from field to OEM
- **Metrics Addendum** - Readiness, logistics, operational, financial metrics

### Purpose for Government Stakeholders

- Improve planning of repair operations
- Reduce downtime of tactical and special vehicles
- Prioritize procurement and logistics
- Identify critical gaps (GAPs)
- Enable transparent communication with OEMs and donors
- Support readiness reporting and budget forecasting

### How to Use This Package

- As a briefing document for leadership
- As a planning tool for logistics and maintenance units
- As a baseline for joint working groups with OEM partners
- As a reference for international support programs

For integration into ministry workflows, IVYAR provides API endpoints, dashboards, and structured data formats.
