# 30-Day Catalog Implementation Roadmap

## Phase 1: Preparation (Days 1-3)
- Create brand-alias tables
- Prepare canonical JSON schema
- Develop ETL scripts
- Create mapping tables

## Phase 2: Vehicle Import (Days 4-10)
- Import Toyota, Mitsubishi, Nissan, Ford
- Import MAN, Volvo, Scania
- Build initial ML index

## Phase 3: Engine & Brakes (Days 11-15)
- Import Cummins, Perkins, Deutz
- Import WABCO, Knorr-Bremse
- Build cross-reference tables

## Phase 4: Electrical & Filters (Days 16-20)
- Import Bosch, Denso, Delphi
- Import Mann-Filter, Mahle
- Generate ML embeddings

## Phase 5: Tires & Transmission (Days 21-25)
- Import Michelin, Goodyear
- Import Allison, ZF
- Run ML drift test

## Phase 6: Validation & Launch (Days 26-30)
- Manual review 1% records
- Automated consistency checks
- Audit report
- Production launch
