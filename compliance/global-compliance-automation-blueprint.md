## 1. Automation Layers

### Layer 1: Data Ingestion

- Sanctions lists (OFAC, EU, UK, UN)
- Export control databases
- OEM data feeds
- Logistics risk data
- Country risk indices

### Layer 2: Classification Engine

| Regime | Automation |
|--------|------------|
| ECCN | Automated classification |
| EU Dual-Use | Automated classification |
| UK ML | Automated classification |
| CA ECL | Automated classification |
| AU DSGL | Automated classification |
| UA Export | Automated classification |

### Layer 3: Sanctions Engine

- Real-time screening
- Automated blocking
- Partial match queue
- Appeals workflow

### Layer 4: Risk Engine

- OEM risk scoring
- Country risk scoring
- Supply chain risk scoring
- Composite risk calculation

### Layer 5: ML Explainability

- Anomaly detection
- Decision logging
- Human-readable explanations
