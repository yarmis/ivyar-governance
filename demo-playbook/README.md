Deliver compelling demos to stakeholders.

| Audience | Focus | Duration |
|----------|-------|----------|
| Ministry | Overview, value | 30 min |
| NATO | Integration | 45 min |

| OEM | Catalog, API | 45 min |

| Type | Use Case |
|------|----------|

- Clear value shown
- Questions answered
- Next steps agreed
