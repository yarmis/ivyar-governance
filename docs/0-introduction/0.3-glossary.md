# Glossary

## Key Terms
- **Agent** — Autonomous software component performing tasks
- **Audit Trail** — Chronological record of actions and decisions
- **Compliance Engine** — Component verifying regulatory compliance
- **Evidence Chain** — Immutable log for audit purposes
- **Explainability** — Capability to explain AI decisions
- **Governance Layer** — Distinct architecture level (1-11)
- **Invariant** — Rule that must always be satisfied
- **Ontology** — Framework defining concept relationships
- **Risk Score** — Numerical risk assessment
