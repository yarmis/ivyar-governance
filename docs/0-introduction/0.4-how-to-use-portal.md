# How to Use This Portal

## Audience Types
- **Ministry Officials** — Oversight, compliance reporting
- **Auditors** — Audit methodology, evidence chains
- **Technical Integrators** — API, system integration
- **OEM Partners** — Integration, certification
- **Donors** — Transparency, fund tracking
- **Academy Participants** — Curriculum, certification

## Document Conventions
- **H1 (#)** — Document title
- **H2 (##)** — Major sections
- **Bold** — Key terms
- `Code` — Technical terms
