# Governance Structure

## Institutional Hierarchy
```
Board of Directors (Strategic Oversight)
        │
Executive Leadership (Operations)
        │
    ┌───┼───┐
Technical  Ethics  Operations
Council   Council   Council
        │
   Working Groups
```

## Decision-Making Bodies
- **Board of Directors** — Strategic oversight, policy, appointments
- **Executive Leadership** — CEO, CTO, Chief Ethics Officer, CCO
- **Advisory Councils** — Technical, Ethics, Operations

## Oversight Mechanisms
- Internal Audit Function
- Ethics Review Board
- Risk Management Committee
- Independent External Auditors
