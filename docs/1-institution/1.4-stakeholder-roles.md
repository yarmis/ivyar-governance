# Stakeholder Roles

## Internal Stakeholders
- **Platform Operators** — Day-to-day operation
- **System Administrators** — Configuration, user management
- **Compliance Officers** — Compliance verification
- **Ethics Reviewers** — Ethical evaluation

## External Stakeholders
- **Ministry Officials** — Government oversight
- **OEM Partners** — Product/service providers
- **Auditors** — Independent verification
- **Donors** — Funding providers
- **Beneficiaries** — Aid recipients

## Segregation of Duties
| Function | Cannot Also Perform |
|----------|---------------------|
| Transaction Initiation | Transaction Approval |
| System Administration | Audit Functions |
| Compliance Review | Operations Execution |
