# Ethical Engine — Gospel Golden Rules

## Core Principles
| Principle | Application |
|-----------|-------------|
| Reciprocity | Evaluate actions by reversing roles |
| Beneficence | Prioritize positive outcomes |
| Justice | Ensure fairness in processes |
| Solidarity | Consider shared responsibility |
| Dignity | Respect inherent human worth |

## Ethical Invariants (Non-overridable)
1. No harm to civilians
2. No exploitation of vulnerable
3. Transparency requirement
4. Human accountability
5. Proportionality

## Scoring Model
| Score | Interpretation | Action |
|-------|----------------|--------|
| 90-100 | Excellent | Auto-approve |
| 70-89 | Acceptable | Approve with logging |
| 50-69 | Concerns | Review required |
| 30-49 | Significant | Senior review |
| 0-29 | Violation | Block, escalate |

## Safeguards
- Human override capability
- Escalation triggers
- Circuit breakers
- Full audit trail
