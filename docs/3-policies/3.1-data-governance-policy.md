# Data Governance Policy

## Data Classification
| Level | Label | Description |
|-------|-------|-------------|
| 1 | Public | Openly available |
| 2 | Internal | Business use only |
| 3 | Confidential | Restricted access |
| 4 | Secret | Highly restricted |
| 5 | Top Secret | Maximum protection |

## Data Lifecycle
1. Creation → 2. Storage → 3. Processing → 4. Sharing → 5. Archival → 6. Deletion

## Access Control Principles
- Need-to-know basis
- Least privilege
- Separation of duties
- Default deny

## Retention Periods
| Data Type | Retention |
|-----------|-----------|
| Transaction records | 7 years |
| Audit logs | 10 years |
| Personal data | As needed |
