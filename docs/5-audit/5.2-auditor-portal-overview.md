# Auditor Portal Overview

## Portal Capabilities
- Evidence Chain access
- Log search and filtering
- Report generation
- Finding documentation

## Auditor Roles
| Role | Access | Capabilities |
|------|--------|--------------|
| External Auditor | Read-only | Full evidence access |
| Internal Auditor | Read-only | Full access + tools |
| Lead Auditor | Read + Export | All + report generation |

## Reporting Tools
- Automated report templates
- Finding tracking
- Trend analysis
- Compliance dashboards
