# Versioning & Change Log

## Versioning Rules
- **Major (X.0.0)** — Breaking changes
- **Minor (0.X.0)** — New features
- **Patch (0.0.X)** — Bug fixes

## Change Log Format
```

### Added
### Changed
### Fixed
### Removed
### Security
```
