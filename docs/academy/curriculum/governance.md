# CURRICULUM - GOVERNANCE TRACK

## Purpose
Teach governance-oriented thinking: ministry processes, coordination, treaties, federations.

## Modules
1. Government Operator Layer (1.0-4.0)
2. Global Governance (6.0-7.0)
3. Treaty Networks (9.0)
4. Federation Governance (11.0)

## Outcome
Students understand governance structures and can reason about treaties conceptually.
