# IVYAR 2.0 DEMO SCRIPT FOR MINISTRIES

## Duration: 15-20 minutes

---

## 1. Introduction (1 min)

**Purpose:** Create transparent, controlled, auditable infrastructure for defense and humanitarian procurement.

**Ministry Problem:** Fragmented data, manual checks, sanctions risks, no unified portal.

**IVYAR 2.0 Solution:** Unified portal, automated compliance, API marketplace, partner collaboration.

---

## 2. Dashboard (2 min)

- Real-time risk overview
- RFQ status, contracts, verifications
- Analytics: sanctions, risks, supply routes

---

## 3. RFQ to Quote to Approval Flow (3 min)

1. Ministry creates RFQ
2. Partners receive request in Partner Portal
3. IVYAR automatically runs Compliance Engine
4. System generates risk profile and recommendations
5. Ministry approves or rejects

---

## 4. Compliance Engine 2.0 Demo (3 min)

- Sanctions checks: OFAC, EU, UK, UA
- Export control: ITAR, EAR, UA
- AI risk signals: routes, OEM, countries, logistics
- Full audit log

---

## 5. API Marketplace (2 min)

- API access for partners and OEMs
- Sandbox for testing
- Governance and billing

---

## 6. Conclusion (1 min)

**Benefits:** Transparency, speed, audit, control.

**Next Steps:** Integration, pilot, staff training.
