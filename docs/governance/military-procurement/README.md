# IVYAR Military Procurement Governance Package

**Version:** 1.0  
**Status:** Ministry-ready  
**Date:** 2025-12-28

---

## EN — English

This package contains the full governance, compliance, ethical and audit structure for the IVYAR Military Procurement module. It includes the portal HTML file, documentation, assets, evidence chain structure, and integrity manifests.

### Structure

- `portal/` — main portal page and assets
- `docs/` — legal, ethical and compliance documentation
- `evidence/` — logs, manifests, audit exports
- `manifest.json` — integrity and metadata manifest
- `checksums.sha256` — SHA-256 checksums for all files

### Purpose

This ZIP package is intended for:
- Ministries
- Auditors
- International partners
- Compliance officers
- Governance reviewers

### Key Documents

1. **Legal Framework** — National law, international treaties, export control, sanctions
2. **Ethical Framework** — Gospel Golden Rules, humanitarian principles
3. **Compliance Engine 3.0** — LegalGuard, Risk Engine, Ethical Engine, Drift Detector
4. **Evidence Chain** — Immutable logging, explainability graphs, audit exports
5. **Audit Interface** — Internal, ministerial, international audit support

## UA — Українська

Цей пакет містить повну структуру governance, compliance, етики та аудиту для модуля військових закупівель IVYAR. Він включає HTML-файл порталу, документацію, ресурси, структуру Evidence Chain та маніфести цілісності.

### Структура

- `portal/` — головна сторінка порталу та ресурси
- `docs/` — юридична, етична та compliance документація
- `evidence/` — логи, маніфести, аудитні експорти
- `manifest.json` — маніфест цілісності та метаданих
- `checksums.sha256` — SHA-256 контрольні суми для всіх файлів

### Призначення

Цей ZIP-пакет призначений для:
- Міністерств
- Аудиторів
- Міжнародних партнерів
- Фахівців з комплаєнсу
- Рев'юерів governance

### Ключові документи

1. **Юридичні рамки** — Національне законодавство, міжнародні договори, експортний контроль, санкції
2. **Етичні рамки** — Євангельські Золоті Правила, гуманітарні принципи
3. **Compliance Engine 3.0** — LegalGuard, Risk Engine, Ethical Engine, Drift Detector
4. **Evidence Chain** — Незмінне логування, графи пояснюваності, аудитні експорти
5. **Audit Interface** — Підтримка внутрішніх, міністерських, міжнародних аудитів
