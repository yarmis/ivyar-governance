# Audit Interface

## Overview / Огляд

IVYAR provides structured, role-aware views of military procurement governance for internal and external auditors.

IVYAR надає структуровані, рольово-орієнтовані представлення управління військовими закупівлями для внутрішніх та зовнішніх аудиторів.

## Audit Types / Типи аудитів

### Internal Audit / Внутрішній аудит
**EN:** Focuses on policy adherence, process consistency and completeness of logs.

**UA:** Зосереджується на дотриманні політик, послідовності процесів та повноті логів.

### Ministerial Review / Міністерський огляд
**EN:** Provides high-level summaries, risk profiles and ethical assessments.

**UA:** Надає узагальнені звіти, профілі ризиків та етичні оцінки.

### International Missions / Міжнародні місії
**EN:** Supports cooperation with trusted partners and oversight bodies.

**UA:** Підтримує взаємодію з довіреними партнерами та наглядовими структурами.

## Features / Можливості

1. **Role-based access** — different views for different audit roles
2. **Export capabilities** — ZIP packages with checksums
3. **Real-time monitoring** — live dashboard for active cases
4. **Historical analysis** — search and filter past decisions

## Integration / Інтеграція

Audit Interface integrates with:
- Evidence Chain for immutable logs
- LegalGuard for compliance reports
- Risk Engine for risk profiles
- Ethical Engine for ethics assessments
