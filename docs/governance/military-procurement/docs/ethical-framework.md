# Ethical Framework / Етичні рамки

## Overview / Огляд

IVYAR embeds a Gospel-aligned ethical layer that evaluates decisions not only against law, but also against civilizational responsibility, humanitarian impact, and long-term peace and security.

IVYAR вбудовує етичний рівень, узгоджений із Євангельськими Золотими Правилами, який оцінює рішення не лише з точки зору закону, а й з точки зору цивілізаційної відповідальності, гуманітарних наслідків та довгострокової безпеки й миру.

## Ethical Invariants / Етичні інваріанти

### 1. Do No Harm / Не нашкодь
Decisions must minimize unintended harm, especially to civilians and humanitarian operations.

Рішення мають мінімізувати ненавмисну шкоду, особливо для цивільних та гуманітарних операцій.

### 2. Proportionality / Пропорційність
Capabilities and support must be proportionate to legitimate defence needs and obligations.

Можливості та підтримка мають бути пропорційними легітимним оборонним потребам та зобов'язанням.

### 3. Transparency / Прозорість
Decisions and justifications should be explainable to authorized oversight bodies.

Рішення та їх обґрунтування мають бути пояснюваними для уповноважених органів нагляду.

### 4. Responsibility / Відповідальність
Actors remain accountable for their decisions; IVYAR supports but does not replace responsibility.

Суб'єкти залишаються відповідальними за свої рішення; IVYAR підтримує, але не замінює відповідальність.

### 5. International Security / Міжнародна безпека
Decisions should contribute to, not undermine, international peace and stability.

Рішення мають сприяти міжнародному миру та стабільності.

### 6. Gospel Golden Rules / Євангельські Золоті Правила
Treat others with the same fairness and dignity one expects in return.

Ставитися до інших з тією ж справедливістю та гідністю, на яку очікуєш для себе.

## Implementation / Впровадження

The Ethical Engine evaluates all decisions against these invariants and flags conflicts for human review.

Ethical Engine оцінює всі рішення на відповідність цим інваріантам та позначає конфлікти для перегляду людиною.
