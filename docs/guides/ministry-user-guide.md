# IVYAR MINISTRY USER GUIDE

**Version:** 1.0  
**For:** Government Users

---

## 1. Access

- Navigate to: ministry.ivyar.org
- Enter government credentials
- MFA required

## 2. Main Sections

- Dashboard
- Readiness
- Risk
- Procurement
- Documentation
- Audit

## 3. Searching for Parts

1. Enter NSN or Part Number
2. Select part from results
3. Review technical profile

## 4. Procurement

1. Add part to RFQ Cart
2. Send RFQ to suppliers
3. Receive Quotes
4. Compare offers
5. Create Purchase Order
6. Track delivery

## 5. Audit

- All actions logged
- Each document has unique ID
- Export journals available
- Full compliance trail
