# IVYAR OEM INTEGRATION GUIDE

## Version: 1.0

## 1. Purpose
Guide OEMs to integrate with IVYAR procurement systems.

## 2. Integration Models
API integration, Vendor portal, Manual RFQ, Automated quoting

## 3. API Requirements
OAuth2, JSON payloads, HTTPS only

## 4. Endpoints
Search, RFQ, Quotes, PO, Vendor profile

## 5. Data Requirements
Part numbers, NSN, Lead times, Pricing, Certificates

## 6. Security
MFA, Token rotation, IP allowlists

## 7. Testing
Sandbox environment, Test RFQs, Test quotes

## 8. Onboarding
Partner agreement, API key, Test integration, Production activation
