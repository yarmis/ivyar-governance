# IVYAR 5.0 - COMPLIANCE AGENT

## Autonomous Risk Brain

---

## 1. Overview

Compliance Agent is the autonomous risk brain that works independently to block or allow operations.

## 2. Core Features

- Sanctions checks (OFAC, EU, UK, UA)
- Export control verification
- Route analysis
- OEM and supplier evaluation
- Autonomous decisions: Allow / Block / Review

## 3. Behavior

- Has own Knowledge Graph
- Constantly updates risk models
- Can stop any operation

## 4. Architecture

Knowledge Graph -> ML Risk Engine -> Decision Engine -> Explainability Layer -> Audit Layer
