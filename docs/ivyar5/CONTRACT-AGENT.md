# IVYAR 5.0 - CONTRACT AGENT

## Legal AI Agent

---

## 1. Overview

Contract Agent is the legal AI that drafts, verifies, and optimizes contracts.

## 2. Core Features

- Automatic contract generation
- Legal clause selection
- Contract risk verification
- Ministry policy synchronization
- Final version generation

## 3. Behavior

- Has own Legal Template Engine
- Works with Compliance Agent
- Passes contracts to Procurement Agent

## 4. Architecture

Legal Template Engine -> Clause Selector -> Risk Analyzer -> Compliance Hooks -> Contract API
