# IVYAR 5.0 - PROCUREMENT AGENT

## Lead Coordinator for Full Procurement Lifecycle

---

## 1. Overview

Procurement Agent is the autonomous agent that manages the entire procurement cycle: from needs analysis to final closure.

## 2. Core Capabilities

- Needs Analyzer
- Autonomous RFQ Generator
- Supplier Matching Coordination
- Quote Evaluation
- Contract Handoff
- Logistics Monitoring
- Final Procurement Closure

## 3. Behavior

- Acts as "Procurement Manager"
- Coordinates all other agents
- Makes decisions based on risk, budget, policies

## 4. Agent Interactions

- Supplier Agent: OEM shortlist
- Contract Agent: Contract drafting
- Logistics Agent: Route planning
- Compliance Agent: Allow/Block/Review decisions
