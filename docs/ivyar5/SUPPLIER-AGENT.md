# IVYAR 5.0 - SUPPLIER AGENT

## AI Negotiator with OEMs

---

## 1. Overview

Supplier Agent is the negotiation agent that manages OEM relationships and creates optimal shortlists.

## 2. Core Features

- Automatic quote requests
- Price and terms negotiation
- OEM Reliability Index evaluation
- Shortlist formation
- Results delivery to Procurement Agent

## 3. Behavior

- Works with OEM APIs
- Considers risks, logistics, history
- Can recommend alternative suppliers

## 4. Architecture

Supplier Graph -> Ranking Engine -> Negotiation Logic -> Quote Optimization -> Risk-Adjusted Ranking
