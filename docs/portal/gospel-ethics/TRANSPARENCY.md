# ETHICAL TRANSPARENCY LAYER

## Purpose
Explains how Gospel rules influenced the answer.

## Transparency Object
- overall_pass: whether all rules passed
- details: rule-by-rule evaluation
- explanation: human-readable summary

## Example
{
  "overall_pass": false,
  "details": [{ "rule_id": "love_neighbor", "pass": false, "details": "Harsh wording detected" }],
  "explanation": ["Draft violated Love Neighbor. Answer was softened."]
}

## Governance
Makes the system auditable, explainable, suitable for governance contexts.
