Admin Onboarding Guide

Complete onboarding process for new administrators joining the IVYAR platform team

1 Welcome to IVYAR Admin Team

Congratulations on your new role as an IVYAR Administrator. This guide will walk you through the complete onboarding process, from initial setup to achieving full operational capability. The onboarding process takes approximately 5 business days.

What to Expect

  • Day 1-2: Documentation, agreements, and initial training
  • Day 3-4: Technical setup and hands-on training
  • Day 5: Shadowing, validation, and access activation

2 Onboarding Timeline

1
Day

Documentation & Agreements

Complete all required paperwork: Confidentiality Agreement, Admin Access Policy acknowledgment, Security Training Registration, Background Check Authorization.

2
Day

Security Training

Complete mandatory security training modules: Security Fundamentals, Admin Responsibilities, Incident Response Basics, Data Protection.

3
Day

Technical Setup

Receive and configure hardware security key, set up MFA, configure admin workstation, install required tools and VPN access.

4
Day

Hands-On Training

Platform walkthrough with mentor, practice in sandbox environment, review common procedures, emergency protocol training.

5
Day

Validation & Activation

Shadow experienced admin, complete competency assessment, receive production access, meet the team.

5 Technical Setup

Hardware Requirements

  • YubiKey 5 NFC (provided by IVYAR)
  • Dedicated admin laptop (hardened configuration)
  • Encrypted USB drive for offline materials
  • Secure phone for MFA codes (backup)

Software & Access Setup

  • VPN client installation and certificate
  • MFA application configuration
  • Admin console access (sandbox first)
  • Monitoring dashboard access
  • Secure communication channels
  • Ticketing system access

9 Getting Help

Support Channels

10 Ongoing Requirements

  • Annual security training recertification
  • Quarterly access review acknowledgment
  • Participation in emergency drills
  • Continuous policy update awareness
  • Regular check-ins with Security Owner
