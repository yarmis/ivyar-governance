2 Heatmap Interpretation

Low Risk

System has stable, verified mechanisms. Requires only regular maintenance and support.

Medium Risk

Mechanisms working but need: automation, regular checks, centralization, documentation.

High Risk

Requires immediate attention as it affects system integrity, ministry trust, audits, and international standards.

3 Strategic Priorities

1
Secrets & Config
High Risk — Immediate Action Required
  • Implement centralized secrets storage (Vault)
  • Ban .env files in repository
  • Add automated secret scanning in CI/CD
  • Add schema-based validation (JSON Schema)
2
Input Validation
Medium Risk — Short-term Improvement
  • Create unified validation middleware
  • Add schema-based validation (JSON Schema / Zod)
  • Centralize validation rules
3
SAST & DAST Automation
Medium Risk — Ongoing Enhancement
  • Automate launch in CI/CD pipeline
  • Add weekly scheduled scans
  • Store results in Audit Log
