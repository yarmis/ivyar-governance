# Government Compliance Playbook

**Document Version:** 1.0  
**Last Updated:** 2025-01-01  
**Classification:** Official

---

## 1. Purpose

This Playbook defines all compliance procedures that ministries and government agencies must follow when working with IVYAR:

- Export control procedures
- Sanctions screening
- Audit requirements
- ML validation
- Risk management
- Access control
- Document management

---

## 2. Compliance Lifecycle

### 2.1. Pre-Procurement Compliance

| Check | Description |
|-------|-------------|
| NSN/FSC/OEM Verification | Validate item identifiers |
| Country of Origin | Verify origin documentation |
| Sanctions Screening | Check against global sanctions lists |
| Dual-Use Assessment | Determine dual-use classification |

### 2.2. RFQ Compliance

| Check | Description |
|-------|-------------|
| Item Verification | Automated check of all line items |
| ECCN Determination | Automatic export classification |
| License Requirements | Identify required licenses |
| RFQ Audit | Complete audit trail creation |

### 2.3. Supplier Compliance

| Check | Description |
|-------|-------------|
| OEM Verification | Confirm original manufacturer |
| Distributor Validation | Verify authorized distributors |
| Certificate Check | Validate certifications |
| Registration Country | Verify supplier jurisdiction |

### 2.4. Order Compliance

| Check | Description |
|-------|-------------|
| Export License | Verify license if required |
| Logistics Verification | Check shipping compliance |
| Document Validation | Confirm required documents |
| Approval Audit | Log all approvals |

## 3. Compliance Controls

### 3.1. Export Control

| Regime | Coverage |
|--------|----------|
| ECCN | US Export Control Classification Numbers |
| EU Dual-Use | European Union Regulation 2021/821 |
| UK ML | UK Military List |
| CA ECL | Canada Export Control List |
| AU DSGL | Australia Defence Strategic Goods List |
| UA Export Control | Ukraine export regulations |

### 3.2. Sanctions

| List | Source |
|------|--------|
| OFAC SDN | US Treasury |
| EU Consolidated | European Union |
| UK Sanctions | UK Government |
| UN Consolidated | United Nations |
| CA Sanctions | Canada |
| AU Sanctions | Australia |

### 3.3. Risk Assessment

| Risk Type | Assessment Method |
|-----------|-------------------|
| OEM Risk | Manufacturer verification score |
| Country Risk | Jurisdiction risk rating |
| Supply Chain Risk | End-to-end supply chain analysis |
| Financial Risk | Payment and credit assessment |

### 3.4. ML Controls

| Control | Description |
|---------|-------------|
| Analytics | Continuous pattern analysis |
| Explainability | Transparent ML decision logging |

## 5. Documentation Requirements

| Requirement | Standard |
|-------------|----------|
| Retention Period | 7 years |
| Change Tracking | All changes logged in changelog |
| Release Documentation | All releases in release notes |
| Access Logs | All document access logged |

---

## 6. Compliance Checklist

### Pre-Procurement

- [ ] Item identifiers verified (NSN/FSC/OEM)
- [ ] Country of origin confirmed
- [ ] Sanctions screening completed
- [ ] Dual-use assessment completed

### RFQ Phase

- [ ] All items compliance-checked
- [ ] ECCN classification completed
- [ ] License requirements identified
- [ ] Audit trail created

### Supplier Selection

- [ ] OEM verification completed
- [ ] Distributor authorization confirmed
- [ ] Certificates validated
- [ ] Supplier jurisdiction verified

### Order Phase

- [ ] Export license obtained (if required)
- [ ] Logistics compliance verified
- [ ] All documents attached
- [ ] Final approval logged

---

## 7. Non-Compliance Procedures

| Severity | Action |
|----------|--------|
| Minor | Document and remediate within 30 days |
| Major | Escalate to Compliance Officer, remediate within 14 days |
| Critical | Immediate escalation, transaction suspended |
