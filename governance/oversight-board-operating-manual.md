# International Oversight Board Operating Manual

**Document Version:** 1.0  
**Last Updated:** 2025-01-01  
**Classification:** Official

---

## 1. Purpose

- Ensure international trust
- Control transparency
- Audit ML, risks, compliance
- Approve changes

---

## 2. Board Composition

| Role | Responsibility |
|------|----------------|
| Ministry Representatives | Government oversight |
| International Experts | Technical review |
| Export Control Lawyers | Legal compliance |
| Technical Auditors | System verification |
| Independent Observers | Neutrality assurance |

---

## 3. Core Responsibilities

### 3.1. Governance

- Policy approval
- Change control
- Risk assessment

### 3.2. Compliance

- Sanctions verification
- Export control review
- ML explainability audit

### 3.3. Audit

- Quarterly audits
- Annual certification
- Audit trail verification

### 3.4. Security

- Incident assessment
- Access control review
- DRP/BCP oversight

---

## 4. Operating Rhythm

| Activity | Frequency |
|----------|-----------|
| Quarterly Review | Every 3 months |
| Annual Certification | Yearly |
| Emergency Review | As needed |

### 4.1. Quarterly Review Agenda

1. Audit summary
2. Compliance summary
3. Risk summary
4. ML validation
5. Action items

### 4.2. Annual Certification

1. Security certification
2. Compliance certification
3. ML certification
4. Operational certification

## 6. Voting Procedures
