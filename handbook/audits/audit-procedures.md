# Audit Procedures

## Audit Types

| Type | Frequency | Scope |
|------|-----------|-------|
| Internal | Monthly | Full system |
| Security | Weekly | Access, data |
| Compliance | Quarterly | Governance |
| External | Annual | Full review |

## Internal Audit

| Check | Owner |
|-------|-------|
| Data accuracy | Analyst |
| User access | Admin |
| Process compliance | Ops Lead |
| Documentation | All |

## Security Audit

| Item | Check |
|------|-------|
| Access logs | Review all |
| Permissions | Verify roles |
| Vulnerabilities | Scan report |
| Incidents | Log review |

## Audit Report

| Section | Content |
|---------|---------|
| Summary | Key findings |
| Issues | List with severity |
| Actions | Required fixes |
| Timeline | Due dates |

## Follow-up

- Issues tracked in system
- Weekly progress review
- Closure verification
- Lessons documented
