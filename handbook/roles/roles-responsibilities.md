# Roles & Responsibilities

## Core Roles

| Role | Responsibility |
|------|----------------|
| Ops Lead | Daily oversight |
| Logistics Officer | Orders, parts |
| Analyst | Risk, readiness |
| System Admin | Technical ops |
| Ministry Liaison | Government comms |

## Ops Lead

- Morning dashboard review
- Escalation decisions
- Weekly reporting
- Team coordination

## Logistics Officer

- Order processing
- Parts tracking
- Supplier contact
- Delivery follow-up

## Analyst

- Risk monitoring
- GAP tracking
- Readiness updates
- Forecast preparation

## System Admin

- Platform uptime
- Data backups
- User access
- Technical support

## Ministry Liaison

- Government reports
- Stakeholder updates
- Approval requests
- Compliance checks
