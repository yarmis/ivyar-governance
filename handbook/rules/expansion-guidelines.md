# Expansion Guidelines

## New Catalog Addition

| Step | Action | Owner |
|------|--------|-------|
| 1 | Request review | Requester |
| 2 | Source verify | Data Team |
| 3 | Schema check | Tech Team |
| 4 | Test import | Data Team |
| 5 | Production add | Ops Lead |

| Step | Duration |
|------|----------|
| Agreement | 2 weeks |
| Technical setup | 1 week |
| Testing | 1 week |
| Go-live | 1 day |
