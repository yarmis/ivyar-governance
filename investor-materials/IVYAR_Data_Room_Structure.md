# IVYAR Due Diligence Data Room Structure

## Overview

This document outlines the recommended structure for IVYAR's investor due diligence data room. A well-organized data room accelerates the investment process and demonstrates operational maturity.

## 📋 Document Priority Matrix

### 🔴 Critical (Required Before Term Sheet)

| Category | Document | Notes |
|----------|----------|-------|
| Corporate | Certificate of Incorporation | Must be current |
| Corporate | Cap Table | Fully diluted, Carta/Pulley export preferred |
| Financial | Financial Model | Interactive Excel with assumptions |
| Financial | Historical Financials | Last 12-24 months |
| Product | Product Demo | Live or recorded |
| Product | Security Documentation | SOC 2, pen tests |
| Team | Founder Agreements | Including vesting |

### 🟡 Important (Required for Due Diligence)

| Category | Document | Notes |
|----------|----------|-------|
| Corporate | Operating Agreement | All amendments |
| Financial | Bank Statements | Last 12 months |
| Financial | Tax Returns | Last 2-3 years |
| Product | Architecture Diagram | Current state |
| Commercial | Sample Contracts | 2-3 representative |
| Commercial | Customer List | Can be anonymized |
| Legal | Material Contracts | Summary + full docs |
| Team | Org Chart | Current + planned |

### 🟢 Supporting (Nice to Have)

| Category | Document | Notes |
|----------|----------|-------|
| Corporate | Board Minutes | Last 12 months |
| Product | Roadmap | 12-18 months |
| Commercial | Case Studies | 2-3 detailed |
| Legal | Insurance Policies | Current coverage |
| Team | Employee Handbook | Shows maturity |

## 🔐 Data Room Best Practices

### Security
- Use enterprise-grade VDR (DocSend, Datasite, Carta)
- Enable watermarking on sensitive documents
- Track viewer activity and downloads
- Require NDA before access

### Organization
- Use consistent naming: `YYYY-MM-DD_Document-Name.pdf`
- Include table of contents / index
- Version control for updated documents
- Separate confidential from standard docs

### Maintenance
- Update monthly or after material changes
- Remove outdated versions
- Track investor questions for FAQ
- Prepare management responses
