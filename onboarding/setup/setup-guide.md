# Setup Guide

## System Requirements

| Item | Minimum |
|------|---------|
| Browser | Chrome, Firefox, Edge |
| Internet | Stable connection |
| Screen | 1280x720 |

## Account Setup

1. Receive invitation email
2. Click activation link
3. Set password
4. Enable 2FA
5. Complete profile

## Profile Setup

| Field | Required |
|-------|----------|
| Name | YES |
| Role | YES |
| Unit | YES |
| Phone | YES |
| Photo | Optional |

## First Login

1. Go to portal.ivyar.org
2. Enter email
3. Enter password
4. Complete 2FA
5. Accept terms
