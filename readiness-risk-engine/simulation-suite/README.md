# Simulation Suite

## Purpose

Test and simulate risk scenarios, readiness changes, and GAP impacts.

## Components

| Component | Description |
|-----------|-------------|
| Scenarios | Predefined risk events |
| Test Data | Sample datasets |
| Models | Behavior simulations |
| Forecasts | Impact predictions |

## Use Cases

- Risk scenario testing
- GAP closure simulation
- Readiness forecasting
- Ministry demo preparation
