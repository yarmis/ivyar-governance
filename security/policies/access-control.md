# IVYAR Access Control Policy

## 1. Purpose

Define access control requirements for IVYAR systems and data.

## 2. Roles & Permissions

| Role | Catalog | Repairs | Fleet | Analytics | Admin |
|------|:-------:|:-------:|:-----:|:---------:|:-----:|
| Operator | Read | Read | Read | - | - |
| Technician | Read | Read/Write | Read | - | - |
| Logistics | Read/Write | Read | Read | Read | - |
| Manager | Read/Write | Read/Write | Read/Write | Read | - |
| Admin | Full | Full | Full | Full | Full |

## 3. Access Request Process

1. Submit request via ticketing system
2. Manager approval required
3. Security review for privileged access
4. Access provisioned within 24 hours
5. Quarterly access review

## 4. Privileged Access

- Requires additional approval
- Time-limited sessions
- Enhanced logging
- Separate credentials

## 5. Service Accounts

- Named owner required
- Minimum privileges
- Password rotation (90 days)
- No interactive login

## 6. Third-Party Access

- Formal agreement required
- Time-limited access
- Enhanced monitoring
- Immediate revocation on contract end

## 7. Access Termination

- Immediate on termination
- Same-day for voluntary departure
- Access review on role change

*Effective Date: December 2025*
