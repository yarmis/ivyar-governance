# Domain Boundaries

## Purpose

Define clear separation between military and aerospace domains.

## Military Domain

| Aspect | Scope |
|--------|-------|
| Focus | Ukrainian defense logistics |
| Users | Ministry, military units |
| Data | Civil parts, NSN mappings |
| Partners | NATO, donors, OEMs |
| Ethics | Humanitarian, defense |

## Aerospace Domain

| Aspect | Scope |
|--------|-------|
| Focus | Generic aviation operations |
| Users | Production, fleet ops |
| Data | Public standards only |
| Partners | None specific |
| Ethics | Industry best practices |

## Never Cross

| Item | Rule |
|------|------|
| Data | No sharing between domains |
| Users | Separate access systems |
| Code | Shared framework, not data |
| Funding | Independent streams |
| Branding | Clear domain identity |
