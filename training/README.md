# IVYAR Training Program

## Purpose

Build competent IVYAR users at all levels.

## Modules

| Module | Duration | Audience |
|--------|----------|----------|
| Basic | 2 hours | All users |
| Operator | 4 hours | Logistics |
| Analyst | 4 hours | Risk team |
| Admin | 6 hours | IT staff |
| Leadership | 1 hour | Management |

## Certification

| Level | Requirements |
|-------|--------------|
| Basic | Module + quiz |
| Operator | Basic + tasks |
| Analyst | Basic + reports |
| Admin | All + system test |

## Delivery

- Self-paced online
- Instructor-led
- Hands-on labs
- Assessment quiz
