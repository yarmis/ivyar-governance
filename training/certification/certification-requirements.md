# Certification Requirements

## Levels

| Level | Badge | Valid |
|-------|-------|-------|
| Basic | IVYAR User | 1 year |
| Operator | IVYAR Operator | 1 year |
| Analyst | IVYAR Analyst | 1 year |
| Admin | IVYAR Admin | 6 months |

## Requirements

| Level | Module | Quiz | Practical |
|-------|--------|------|-----------|
| Basic | YES | 80% | NO |
| Operator | YES | 80% | YES |
| Analyst | YES | 80% | YES |
| Admin | YES | 90% | YES |

## Renewal

| Level | Process |
|-------|---------|
| Basic | Retake quiz |
| Operator | Refresher + quiz |
| Analyst | Refresher + quiz |
| Admin | Full retest |

## Records

- Certificates stored in system
- Manager notified
- Renewal reminders sent
