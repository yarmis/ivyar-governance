# Basic Training Module

## Duration: 2 hours

## Objectives

- Understand IVYAR purpose
- Navigate the portal
- Perform basic search
- Understand dashboard

## Topics

| Topic | Time |
|-------|------|
| Introduction | 15 min |
| Portal tour | 30 min |
| Search basics | 30 min |
| Dashboard | 30 min |
| Quiz | 15 min |

## Hands-On Tasks

1. Login to portal
2. Search for 3 parts
3. View part details
4. Read dashboard status

## Assessment

- 10 questions
- Pass: 80%
- Retry: Unlimited
