# UAT Scenario: Ministry Operator

## Steps

1. Open portal - Login page loads
2. Enter credentials - Dashboard appears
3. Go to Orders - Orders list opens
4. View all orders - Full list displayed
5. Filter by status - Filtered results
6. Filter by date - Date filtered
7. Select order - Order details shown
8. Export data - CSV downloaded
9. Generate report - PDF generated

## Pass Criteria

- All orders visible
- Filters work correctly
- Export generates valid files
