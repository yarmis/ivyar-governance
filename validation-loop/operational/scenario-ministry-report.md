# Scenario: Ministry Operator Generates Report

## Actor
Ministry operator preparing weekly report

## Context
Weekly readiness report for leadership

## Steps

1. Login to portal
2. Navigate to Reports
3. Select date range: last 7 days
4. Select report type: Readiness
5. Filter by platform: All
6. Generate report
7. Review summary data
8. Export to Excel
9. Export to PDF

## Expected Results

- Report loads within 10 seconds
- Data matches dashboard
- All platforms included
- Excel export valid
- PDF formatted correctly

## Data Validated
- Orders count accurate
- R-level distribution correct
- GAPs status current
