# UAT Scenario: Logistics Officer

## Steps

1. Open portal - Login page loads
2. Enter credentials - Dashboard appears
3. Click Search - Search page opens
4. Enter query - Results displayed
5. Select item - Item details shown
6. Add to Request - Item in cart
7. Create Order - Order form opens
8. Submit order - Order confirmed
9. Check status - Status displayed

## Pass Criteria

- All steps complete without error
- Order created successfully
- Status visible in dashboard
